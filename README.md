# Pro Football Manager

A football video game where players can control real football teams and players in matches, with core modes like Career Mode, Ultimate Team, Clubs, and Kick-Off.

Core MVP features

⚽ Realistic football matches — passing, shooting, dribbling, defending and goalkeeping.

Add 2player local for mobile and desktop 

👤 Real players & teams — licensed clubs, leagues and players.



🏆 Career Mode — manage a club/player, transfers, tactics and competitions.



💰 Ultimate Team — build a squad using player cards and compete online.



👥 Clubs — create/customize a player and play with other people.



🎮 Kick-Off — quickly play matches with any available teams. Locally against player in the same keyboard



🌐 Online multiplayer — compete against other players.



📈 Progression — players, teams and custom squads can improve over time.





In one sentence: FC 27's MVP is “a playable football simulation with real teams/players, core offline and online modes, and enough customization/progression to keep players coming back.”
